10)
let age = 20;
let student = {
  name: "Vikas",
  age: 18
};

console.log(age, student);
Output:
20 { name: 'Vikas', age: 18 }

a) Primitive types hold one simple value and are copied by value. Non-primitive types hold many values and are copied by reference.
b) They are called primitive because they are the most basic values, they are not objects and they cannot be changed.
c) Object, for example student = { name: "Vikas", age: 18 }. It is non-primitive because it holds many values together and is stored by reference.
